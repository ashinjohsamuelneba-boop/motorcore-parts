# MotorCore Parts — Chevy, Ford & Toyota

A production-ready static storefront starter.

## Included
- Responsive storefront
- Search/filter inventory
- Chevy/Ford/Toyota categories
- Part request form
- Product cards
- Demo admin dashboard
- Mobile-friendly layout

## Before public launch
1. Replace the placeholder phone/email.
2. Connect the request form to a real email/form endpoint.
3. Move inventory into a database/CMS.
4. Replace the demo admin page with real authentication.
5. Add your actual product photos, prices, warranty terms and shipping policy.
6. Deploy to your chosen hosting provider and connect your domain.

This package intentionally does not contain real payment processing or insecure client-side authentication.
